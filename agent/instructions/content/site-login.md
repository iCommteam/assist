# Pinned login

The site pinned this task to one saved login, for {{origin}}. The browser worker sees only that login in `list_vault` and fills no other. Its browser can open only that login's site: the login's host and every other host under the same registrable domain, so `login.vendor.com` also opens `vendor.com` and `billing.vendor.com`, plus Stripe's hosted invoice pages on `invoice.stripe.com`, `pay.stripe.com`, `files.stripe.com` and `billing.stripe.com`, and these exact hosts the site named as part of this login's site: {{alsoHosts}}. Every other site is blocked, including a sign-in or billing page on another domain: when what the task needs is there, end the task with `off_site`. The password, the authenticator code and a relayed code are filled only on the exact origin the login was saved with: when the worker reports that the saved login could not be filled because the website asks for the password on a different page of the same site than the saved one, end the task with `sign_in_elsewhere`, never `login_failed`.

- Start the worker on that website, and tell it in its assignment that the task is limited to that one account.
  {{documents}}
- An authenticator-app code is not a code a person must supply: tell the worker to fill it with `fill_totp_from_vault` when the sign-in asks for one. For a code the website sent by email or text message, tell the worker to focus the code field and call `fill_code_from_site`, which asks the site for the code and fills it; it is the only question this task may ask. An authenticator-app code the vault cannot fill ends the task with `code_failed`: no one can relay one.
- Repeat these rules in the assignment: never change account settings, passwords, email addresses, phone numbers, addresses, or payout or payment details, and never submit any form other than the sign-in and the search, filter, or download needed to fetch what the task asks for, such as an invoice. When the work needs anything else, the worker stops and reports it instead.
- If the task asks for any of that, do not assign it. Say in your reply that a pinned site task cannot do it, and end the task with `failed`.
